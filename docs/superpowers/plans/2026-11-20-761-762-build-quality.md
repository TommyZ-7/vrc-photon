## Review Focus

- **Corrupt or negative DB values:** rows written by older builds can hold `-1` where the code assumes non-negative. `try_from` must fall back to a documented clamp rather than wrap; covered by Task 7's DB cast conversions.
- **Very large images:** `width * height` can exceed `usize` on 32-bit or be near `u32::MAX` on 64-bit. Clamped conversions must not silently under-allocate; covered by Task 7's `MAX_DECODE_ALLOC_BYTES` sites.
- **Panic-free logging:** the daemon log pass must not panic when the locator/tail invariants change; covered by Task 4.
- **Release-profile regressions:** LTO can slow the first frame or image decode; Task 2 rejects the profile if medians regress beyond 5%.
- **Stripped panic symbols:** `strip = "symbols"` changes crash diagnostics. Nothing in the code depends on symbol names; documented in the PR.

## Risks and mitigations

- **Cast behavior changes:** every `as` replacement uses `try_from` with an explicit clamp/fallback. Review each DB boundary for negative/corrupt values; tests cover normal ranges.
- **FFI casts:** pointer casts cannot be expressed with `TryFrom`; a reasoned function-level allow is the only sound option.
- **LTO build time:** recorded for both profiles. The PR body states the cost; the release workflow is the only place that pays it in CI.
- **`strip = "symbols"`:** panic backtraces lose symbol names. There is no crash reporter; accept and document.
- **Benchmark noise:** Xwayland timing is noisy. Use five runs, medians, and ranges; do not claim a win from a single run.
- **CI denies warnings:** the lint commit must be fully clean; there is no partial warn-only state.
- **Scope creep:** non-core `as_conversions` stays allowed with a reason; do not fix 274 unrelated casts in this PR.
