**Goal:** 「連携・自動」の左一覧に詳細カードと同じ背景を与え（#477）、Photos のセッション折りたたみ・展開を `ui_max_fps` に追従するアニメーションにする（#478）。

**Architecture:** #477 は一覧全体を `glass_panel` のカードに置き換える。 #478 は `PhotoBrowser` にセッション単位の `ToggleMotion` を持たせ、折りたたみ目標でもアニメーション中は写真行を残した行モデルを作る。`GalleryView` は毎フレーム更新される行高を `v_virtual_list` に渡し、0 サイズの animation 要素で再描画を駆動する。

**Tech Stack:** Rust 2024, gpui-kit 0.9, GPUI `with_animation`, `ToggleMotion`, `v_virtual_list`

- [ ] **Step 3: Implement the motion state**

- `animate_to_at` は既存 `animate_to` の本体を移し、`started_at = now` にする。
- `animate_to` は `animate_to_at(target, duration, Instant::now())` を呼ぶ。

- `factors` は非アクティブを `retain` で落とし、`value_at(now)` を返す。
- `max_duration` はアクティブな `duration()` の最大値。空なら `Duration::ZERO`。フレーム駆動の継続時間を毎フレーム短くしないために、残り時間ではなく元の継続時間を使う。
