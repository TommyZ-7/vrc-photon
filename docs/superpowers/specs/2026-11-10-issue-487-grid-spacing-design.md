# 写真グリッドの間隔とカード角丸の設定 (#487) 設計

> 状態: ドラフト（承認待ち）
> モック: `docs/ui-487-grid-spacing-mockup.html`
> 計画: `docs/superpowers/plans/2026-11-10-issue-487-grid-spacing.md`

## 目的

写真グリッドの「画像同士の間隔」と「写真カードの角丸」を設定画面から変更できるようにする。
どちらも現在は固定値で、アプリ再起動なしに Photos（時系列表示・セッション別表示）と
検索結果のグリッドへ反映する。

## 現状

- 横方向のカード間隔は `crates/ui/src/ui/theme.rs` の `GRID_GAP = 14.0`。列数計算
  (`grid_columns`) とカード幅計算 (`photo_card_width`) の両方に使われる。
- 縦方向の行間は同じファイルの `CARD_ROW_GAP = 14.0`。写真行の高さ
  (`photo_row_height`) とセッション見出し行の高さに加算される。
- 写真カードの角丸は `crates/ui/src/ui/gallery.rs` の `render_card` 内で `13.0` に固定。
  内側の画像角丸は `inner_corner_radius(card_radius, 1.0)` で導出する。
- 設定は `crates/core/src/settings.rs` の `AppSettings` に JSON で保存される。
  ギャラリーは毎フレーム `AppSettings` を参照するため、値を更新して保存すれば
  再起動なしで反映できる。
- 設定画面の「表示（ライブラリ・検索）」カードには、圧縮状態・ワールド名・日付・
  サイズの4スイッチがある。ここへ2項目を追加する。

## 決定事項

ユーザーが選んだ方針（2026-11-10）。

| # | 判断項目 | 決定 | 補足 |
|---|---|---|---|
| Q1 | 設定画面の入力方式 | スライダー＋現在値表示 | 既存のサムネイル画質スライダーと同じ操作感。右側に「14 px」のように表示する |
| Q2 | 2項目の配置 | 既存の「表示（ライブラリ・検索）」カード内 | 4スイッチの下に区切り線を挟んで追加する |
| Q3 | 縦方向の間隔 | 横・縦の両方に同じ値を適用 | 既定14 pxは `GRID_GAP` と `CARD_ROW_GAP` の両方と一致する。セッション見出し行の間隔も連動する |
| Q4 | 保存タイミング | ドラッグ中は即時反映、離した時に保存 | `SliderEvent::Change` でメモリ上の値を更新し、`SliderEvent::Release` で `AppSettings::save` を呼ぶ |

実装者が決めた事項。

| # | 判断項目 | 決定 | 理由 |
|---|---|---|---|
| Q5 | 値の粒度 | 1 px 単位の整数 | 範囲が0〜32 / 0〜24と狭く、サブピクセル指定の需要がない。スライダーの `step(1.0)` と保存型を揃える |
| Q6 | 範囲の見せ方 | 各スライダーの下に「カード同士のすき間（0〜32 px）」のような短いヒントを出す | スライダーだけでは上限・下限が分からない。新しい設定なので説明を1行に限定する |
| Q7 | 範囲外の値の扱い | 読み込み時と保存時にクランプする。専用の deserializer で数値以外・負数・上限超過も既定値または範囲内へ丸める | 既存の `#[serde(default)]` だけでは `999` や `-1` で `AppSettings` 全体のパースが失敗し、全設定が初期化される。写真グリッドの設定だけで他の設定を失わないようにする |
| Q8 | 既定値の置き場所 | `vrc-photon-core` の `settings` モジュールに範囲と既定値の定数を置く | 保存層のクランプとUIのスライダー範囲が同じ値を使う。UI側に別の既定値を持たせない |
| Q9 | 保存失敗時 | メモリ上の値は維持し、`tracing::warn!` を出す | 既存のサムネイル画質・カードサイズ変更と同じ扱い。次の操作で再度保存できる |
| Q10 | 設定値の反映範囲 | 写真カードとその内側画像だけ。インスペクタ、ビューア、設定カードなどの角丸は変えない | Issue #487 の対象は写真グリッドのカード。他のカードの角丸はデザイントークンのままにする |
| Q11 | リセット操作 | 追加しない | Issue の範囲外。既定値に戻す場合はスライダーを既定値へ動かせばよい |

## 仕様

### 設定項目

| 設定 | キー | 範囲 | 既定値 | 型 |
|---|---|---|---|---|
| グリッド間隔 | `ui_grid_gap` | 0〜32 px | 14 px | `u8` |
| カード角丸 | `ui_card_radius` | 0〜24 px | 13 px | `u8` |

- どちらも1 px単位。設定画面のスライダーは整数ステップで動く。
- 読み込み時は `AppSettings::load` の正規化で範囲内にクランプする。
- 保存時も `AppSettings::save` が複製を正規化してから書き込む。
- JSON にキーがない場合は既定値を使う。数値以外、負数、上限超過は設定全体の
  パース失敗にせず、既定値または範囲内の値へ丸める。
- 設定値は既存の `app_settings` 行に追加する。DBスキーマ変更はない。

### レイアウトへの適用

- `grid_columns`、`photo_card_width`、`photo_row_height`、`library_grid_metrics`、
  `search_grid_metrics` は `grid_gap` を引数で受け取る。グローバル変数や
  可変静的値は使わない。
- Photos の時系列表示、セッション別表示、検索結果はすべて同じ `render_grid` /
  `render_card` を通るため、設定値は1か所から渡す。
- 列数は `(available_width + gap) / (min_card_width + gap)` で再計算する。
  間隔を広げると列数が減ることがある。カード幅は
  `(available_width - gap * (columns - 1)) / columns` で再計算する。
- 行の高さは画像高さ＋表示中のテキスト行＋`grid_gap`。セッション見出し行、
  日付ラベル行、継続行の高さにも同じ `grid_gap` を加算する。
- カード角丸は `render_card` が `ui_card_radius` を読み、内側画像は
  `inner_corner_radius(card_radius, 1.0)` で導出する。0 px のときは両方0になる。
- グリッド間隔を変更したときは、カードサイズ変更と同じく表示中の先頭写真を
  アンカーとして維持する。セッション表示では折りたたみ状態も維持する。
- 検索結果は Photos と同じカード・同じ間隔・同じ角丸を使う。検索専用の
  別設定は作らない。

## UI

設定画面の「表示（ライブラリ・検索）」カード、4つのスイッチの下に区切り線を置き、
2つのスライダー行を追加する。

各行の構成:

1. 左にラベル、右に現在値（例: `14 px`）
2. スライダー
3. 下に短いヒント（例: `カード同士のすき間（0〜32 px）`）

文言キー:

| キー | ja | en |
|---|---|---|
| `settings.display.grid_gap.label` | グリッド間隔 | Grid spacing |
| `settings.display.grid_gap.hint` | カード同士のすき間（0〜32 px） | Space between cards (0–32 px) |
| `settings.display.card_radius.label` | カードの角丸 | Card corner radius |
| `settings.display.card_radius.hint` | 写真カードの角丸（0〜24 px） | Photo card corner radius (0–24 px) |

- 値の表示は `format!("{} px", value)`。i18n キーにはしない。
- スライダーのドラッグ中は設定画面の値表示と、設定画面を離れた後のグリッドへ
  即時反映する。DB保存は指を離した時だけ行う。
- 設定画面を開いた時点の値でスライダーを初期化する。既存のサムネイル画質と
  同じく、画面を開いたまま外部から設定が変わってもスライダー状態は追従しない。

## 実装方針

1. `crates/core/src/settings.rs`
   - 範囲・既定値の定数を追加する。
   - `ui_grid_gap: u8` と `ui_card_radius: u8` を追加する。
   - 専用 deserializer と `normalize_grid_display` を追加し、`load` / `save` から呼ぶ。
2. `crates/ui/src/ui/theme.rs`
   - レイアウト関数へ `grid_gap: f32` を追加する。
   - 既存の `GRID_GAP` / `CARD_ROW_GAP` はテストと初期値の基準として残すか、
     core の既定値へ置き換える。実装時は二重定義を避ける。
3. `crates/ui/src/ui/gallery.rs`
   - `render_grid` / `render_sessions` が `app.settings.ui_grid_gap` を読む。
   - `render_card` が `app.settings.ui_card_radius` を読む。
   - `render_page_error` の `CARD_ROW_GAP` を渡された `grid_gap` に置き換える。
4. `crates/ui/src/app/session.rs`
   - セッション行の高さ計算で `CARD_ROW_GAP` の代わりに設定値を読む。
5. `crates/ui/src/app.rs` / `crates/ui/src/ui/settings.rs`
   - `SliderState` を2つ追加し、サブスクリプションで Change / Release を処理する。
   - 設定画面に2行を追加する。
6. `crates/i18n/locales/ja.yml` / `en.yml`
   - 4キーを追加する。

## 非対象

- インスペクタ、ビューア、設定カード、モーダルなど写真カード以外の角丸。
- カードサイズ（小 / 中 / 大 / 特大）の選択肢や最小幅の変更。
- グリッドのアニメーション、フェード、スタッガー。
- 設定のプリセット、リセットボタン、テーマごとの既定値。
- DBスキーマの変更や設定の別テーブル化。
- デーモン側の設定再読込。UIのみで完結する。

## テスト

- core: 既定値、キー欠落時の既定値、範囲外（33 / 255 / 999 / -1 / 文字列）の
  クランプ、保存時のクランプ。
- theme: 既定の間隔で既存の列数・カード幅・行高が変わらないこと。
  間隔0 / 14 / 32 で列数・カード幅・行高が計算どおりになること。
  検索グリッドも同じ計算になること。
- gallery / session: タイムラインとセッション表示の行高・列数が設定値に追従すること。
  間隔変更後も先頭写真のアンカーが維持されること。
- i18n: ja / en の両方に4キーが存在すること。
- 手動確認: `--demo` で設定を0 / 14 / 32、角丸を0 / 13 / 24へ動かし、
  Photos の時系列・セッション別・検索結果でカード間隔と角丸が一致すること。
  再起動後も値が残ること。

## リスク

- 間隔を大きくすると列数が減り、行高も変わる。仮想リストのスクロール位置が
  飛ばないよう、既存のアンカー処理を通す。
- セッション表示は見出し行・日付行・継続行の高さにも間隔が入るため、
  行モデルの再構築漏れがあるとクリック位置やスクロール位置がずれる。
  高さを使う全経路を同じ設定値に揃える。
- 設定値の型を `u8` にすると JSON の範囲外整数でパースが失敗する。
  専用 deserializer を必ず通す。
