# 余計な表記の削除 (#490) 設計

> 状態: モック・設計は承認済み。実装は PR #510 で完了。
> モック: `docs/ui-490-remove-labels-mockup.html`

## 目的

Issue #490 に列挙された UI のラベル・ヒント・ツールチップ・注記を削除する。各項目は
表示要素そのものと i18n キー（ja / en）を削除し、呼び出し側のコードも取り除く。
削除の結果、見出しやカード・セクションの中身が空になる場合は、その見出し・領域ごと
削除する。

エラーメッセージ、同意・ライセンス文面、破壊的操作の警告文は対象外。Issue #491 の
「出し分け・集約・部分削除」のうち、AI カードの状態ラベルはモック承認時の指示により
本設計で削除する。それ以外の #491 項目は対象外とする。

## 対象

- Photos のインスペクタ、クイックルック詳細、ビューアの閉じるボタン
- ダッシュボードの AI カード、ログ、削除待ち
- サイドバーの進捗カード、通知モーダル
- 連携・自動の AI / 自動圧縮 / クリップボード / Discord
- 設定の AI、言語、表示、サムネイル、テーマ、起動、フッター
- 圧縮設定、手動圧縮ダイアログ、圧縮キュー
- 検索、AI タグピッカー、ギャラリーのエラー表示、取り込み先
- ダッシュボード AI カードの状態ラベル（準備不足・待機中・実行中・失敗をすべて削除）
- `crates/i18n/locales/ja.yml` / `en.yml` の該当キー
- `crates/i18n/tests/placeholders.rs` の `settings.footer.summary` 登録

## 対象外

- Issue #491 の項目のうち、AI カードの状態ラベル以外（正常時は表示しない、1 か所へ集約、
  部分削除）。
- 新しい文言・アイコン・設定項目・レイアウトの追加。
- エラー、同意、ライセンス、破壊的操作の警告。
- キー削除の副作用で未使用になるが、Issue #490 に列挙されていないキー
  （`compression.use_for_auto`、`settings.cache.unlimited`）の削除。

## 方針

1. 対象キーを ja / en の両カタログから削除する。
2. `tr!` / `tr_args!` の呼び出しと、その表示要素を削除する。
3. 表示要素がカード・見出し・セクションの唯一の中身だった場合は、外側の
   カード・見出し・セクションも削除する。
4. 説明文だけを削除するスイッチ・ラジオ行は、ラベルと操作を残し、説明ノードを
   描画しない。空文字を渡したときに説明ノードと `gap` を出さないよう、共通
   ヘルパーを空説明対応にする。
5. 固定高の仮想リスト行（圧縮キューの失敗ヒント）は、行の種類ごと削除する。
6. 文言の変更は `viewer.close` の「閉じる Esc」→「閉じる」だけに限定する。
   キー自体は残す。

## 画面ごとの変更

### Photos / インスペクタ / ビューア

- 未選択時: 案内カード（`photos.select_prompt` / `photos.select_prompt_hint`）を削除。
  列幅は維持し、空のカードは描かない（Q3）。
- インスペクタヘッダー: 「Space で開く」を削除。「選択中」は残す。
- AI タグパネル: 「読み取り専用」を削除。タグ 0 件時は空状態の 2 行とタグブロックを
  出さない（Q5）。
- 圧縮履歴: 0 件時は見出しごと出さない（Q6）。
- メモ: 空ボックスを出さない（Q10）。編集中の「Esc でキャンセル」を削除。
- ビューア: 閉じるボタンを「閉じる」/「Close」に変更（Q1）。

### ダッシュボード / 自動起動

- AI カード: ロボットアイコン、サブタイトル、待機中ヒント、準備不足ヒントを削除。
  タイトル・件数・ジョブ一覧・操作ボタンは残す。状態ラベル（準備不足・待機中・実行中・
  失敗）はすべて出さない（Q13）。
- ログ: 24 時間保持のアンバー注記をカードごと削除。「OS のファイラーで開きます」を削除。
- 削除待ち: 末尾の説明を削除。
- 自動起動: systemd 管理時の説明を削除し、説明なしでスイッチを表示（Q2）。

### サイドバー / 通知

- スキャン待機・取り込み未実行の詳細行を削除（空なら描画しない、Q9）。
- 「未実行を開始」「再スキャン」のツールチップを削除。
- 通知モーダル: 空メッセージを削除し、通知対象なしでは開かない（Q4）。

### 連携・自動 / Discord

- AI の有効化・自動・バックログの説明、バックログ開始の説明、バックエンド説明、
  実行中 3 件の注記、有効化後の選択注記、空ジョブの補足を削除。
- 自動圧縮・クリップボード・Discord・送信履歴のサブタイトルを削除。
- Discord 送信タイミング 3 択の説明を削除し、ラベルだけにする（Q8）。

### 設定

- AI: probe 未実行の警告、インストール説明、ダウンロード注記、variant 注記、
  タグ別閾値の説明を削除。警告ボックス関数が未使用になるため削除する。
- 言語・テーマ: 説明文を削除。
- 表示: 4 スイッチの説明を削除し、ラベルだけにする。
- サムネイル: 画質・解像度の注記、キャッシュ削除の注記を削除。
- 起動: トレイ常駐の説明を削除。systemd 管理時の自動起動説明も削除（Q2）。
- フッター: 言語・キャッシュ上限の要約を削除。「設定を再読込」は残す（Q11）。

### 圧縮 / 手動圧縮

- プロファイル編集: ロスレス時の「品質指定を使用しません」を削除。品質の増減が
  無効であることは操作状態で示す。「品質を調整」は非ロスレス時だけ表示する。
- 保存ヒントのコールアウトを削除。
- キュー: 失敗ヒント行を削除（Q7）。
- 手動圧縮ダイアログ: 冒頭説明と「実行のたびに出力先を選びます」を削除。

### 検索 / 取り込み

- 検索フィルターの「カテゴリ間は AND、カテゴリ内は OR」を削除。
- AI タグの「いずれか（OR）」注記、AI タグピッカーの説明を削除。
- ギャラリーのエラー時の再読込案内、取り込み先の変更方法の注記を削除。

## リスクと確認

- カタログのキー削除漏れ・呼び出し漏れ。`rg` で対象キーが 0 件になることを確認する。
- 空説明対応の共通ヘルパー変更が他のスイッチ・ラジオ行へ影響しないこと。
  空文字を渡した行だけ説明が消え、既存の説明は残ることをテストで確認する。
- 圧縮キューの行数・高さが変わるため、仮想リストのテスト期待値を更新する。
- 通知モーダルを開かない条件が、既存の通知対象（取り込み・ライブラリ・圧縮・
  デーモン）を誤って塞がないこと。
- 未選択インスペクタの列幅維持が、既存の列幅計算・リサイズ・詳細パネル開閉と
  矛盾しないこと。
- `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、
  `cargo test --workspace` を通す。

- 空になった見出し・カード・セクション・キュー行が残っていない。
- スイッチ・ラジオ・ボタン・件数・エラー表示など、削除対象外の情報と操作は
  従来どおり動作する。

- 未選択インスペクタ、通知なし、AI タグ 0 件、圧縮履歴 0 件、ロスレス品質、
  圧縮キュー失敗あり、の各状態で余白だけの領域が残らない。
- ローカル検証コマンドがすべて通る。
