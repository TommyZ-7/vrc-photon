# #521 設定・連携カードの項目区切り線 設計

- Issue: #521「設定と連携・自動の各カードに項目ごとの区切り線を追加する」
- Mock: `docs/ui-521-card-separators-mockup.html`
- 状態: モック確認待ち（実装未着手）

## 目的

設定画面と「連携・自動」画面の各カードで、項目の切れ目を視覚的に分かりやすくする。
新しい情報や操作は追加せず、既存レイアウトに 1px の区切り線だけを足す。

## 対象

- 設定画面のカード
  - 言語 / テーマ / ライブラリ / AI タグ付け / ワールド名解決 / 表示 /
    パフォーマンス / サムネイル / 起動 / アップデート / ログ
- 「連携・自動」画面の詳細ペインのカード
  - Discord 連携 / 送信履歴 / 自動圧縮 / AI タグ付け / クリップボード

## 対象外

- 「連携・自動」画面の左側マスター一覧カード（ナビゲーション）
- 送信履歴の各行、プロファイル一覧の各行
- モーダル、トースト、ダイアログ

## 項目の定義

各カードの最上位の子要素を 1 項目とする。
見出しも 1 項目として扱う。スライダーのラベルと値、注記、複合ブロック
（プロファイル一覧、ジョブ詳細、Webhook 設定など）の内部は分割しない。

条件付きで表示される要素（警告、エラー、ダウンロード進捗など）は、
表示されている場合のみ項目として数える。

## 描画ルール

1. 線は高さ 1px、色は `palette.line_soft`。
2. カードの子要素として挿入し、左右はカードの 14px パディングの内側に揃える。
3. 項目と項目の間にのみ挿入し、最後の項目の後には挿入しない。
4. カードの `p(px(14.))`、`gap(px(12.))`、幅、角丸、背景、影は変更しない。
5. 表示カードのトグル群とスライダー群の間にある既存の境界線は残す。
   その位置には新しい線を追加せず、既存の 1 本を区切りとして使う。
6. 文言、設定値、保存処理、表示条件、スイッチの動作は変更しない。

## 実装方針

- `crates/ui/src/ui/components.rs` に区切り線ヘルパーを追加する。
- 各カードの子要素の間にヘルパーを挿入する。
- 動的に子要素を追加するカードは、追加が発生した直前にのみ区切り線を入れる。
- 表示カードの既存 `div().h(px(1.)).bg(rgba(p.line_soft))` はそのまま残す。

## 受け入れ条件

- 対象カードの各項目間に 1px の区切り線がある。
- 各カードの最後の項目の下に線がない。
- 線の左右がカード内側の余白に揃っている。
- 表示カードの既存グループ境界線が 1 本のまま残っている。
- カードの並び、幅、パディング、項目構成、文言、設定動作に変化がない。
- ダークテーマとライトテーマで線が背景から浮きすぎない。
