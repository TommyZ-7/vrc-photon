# 取り込み対象を PNG のみに絞る (#681) 設計

> 状態: 実装完了（2026-11-17）
> モック: なし（画面レイアウトの変更はなく、ファイル選択ダイアログのフィルタ名だけを変更する）
> 対象 Issue: #681

## 目的

VRChat が出力する PNG 写真だけを索引・監視・取り込みの対象にする。Steam の
スクリーンショット機能で保存された JPG など、VRChat の写真ではない JPG/JPEG が
ライブラリに混ざらないようにする。

## 現状

- `crates/core/src/photo_filename.rs` の `is_source_photo` が `png` / `jpg` / `jpeg` を
  許可している（大文字拡張子も可）。
- この関数は次の経路で共通に使われている。
  - 写真ルートの走査: `crates/core/src/scanner.rs` の `walk` と `scan_one_detailed`
  - デーモンのファイル監視: `crates/daemon/src/lifecycle.rs` の `poll_watchers`
  - 手動取り込み: `crates/core/src/importer.rs` の `collect_folder_sources` と `import_one`
  - UI のファイル選択フィルタ: `crates/ui/src/app/import.rs` の `pick_import_files`
- ワールド情報の XMP 読み取りは `crates/core/src/metadata.rs` の `read_xmp` が
  PNG 専用で、JPG では `None` を返す。現行どおり変更しない。
- 走査と取り込みは、ディレクトリ名が `compressed` のサブツリーを除外している。
  圧縮の出力形式は JPEG / WebP / AVIF / JPEG XL で、PNG 出力は存在しない。
- フルスキャンは、走査で見つからなかった既存行を `missing` にする
  （`crates/daemon/src/scan.rs`）。既存 DB は 1 から作り直す前提のため、JPG 行の
  移行・削除は行わない。

## 仕様

### 対象形式

- 拡張子 `png` のみを対象とする。大文字拡張子（`.PNG`）も対象にする。
- `jpg` / `jpeg` は走査・監視・手動取り込みのすべてで対象外とする。
- 対象外のファイルはエラーや失敗件数に数えず、単に対象から外す。
  手動取り込みで明示的に選択された場合は、従来の非対応ファイルと同じく
  `skipped` に数える。

### 写真の索引と監視

- 起動時のフルスキャンは PNG だけを索引する。
- `notify` の作成・変更イベントは PNG だけを増分索引の対象にする。
- 既存行が JPG の場合、次回のフルスキャンで `missing` になる。移行処理は入れない。
- `compressed/` の除外、シンボリックリンクの除外、寸法を読めないファイルの失敗記録は
  現行どおり。

### 手動取り込み

- ファイル選択ダイアログのフィルタは `png` だけを許可し、表示名を
  `PNG 画像` / `PNG images` にする。
- フォルダ取り込みは PNG だけを収集する。
- 直接指定された JPG/JPEG は `skipped` として数え、取り込み先へコピー・移動しない。
- 取り込み後の再スキャン、階層維持、キャンセル、再試行などの既存挙動は変えない。

### 対象外

- JPG/JPEG のデコード・表示・サムネイル・MCP 配信・タグ付けスナップショットは
  引き続き対応する。既存の JPG 写真を表示できなくする変更ではない。
- XMP の解析、圧縮形式、圧縮の出力先、DB スキーマは変更しない。
- 圧縮生成物のうち PNG のパスを DB から除外する仕組みは、今回は追加しない。
  圧縮形式に PNG が加わった時点で、derivative パスを索引対象から外す対応を行う。

## テスト

- `is_source_photo` が PNG（大文字含む）だけを許可し、JPG/JPEG/WebP を拒否する。
- フォルダ走査が PNG だけを返し、JPG/JPEG を無視する。
- `scan_one` が JPG を `None` にする。
- 手動取り込みが PNG をコピーし、JPG/JPEG を `skipped` にする。
- フォルダ取り込みの収集が JPG/JPEG を除外する。
- 監視の作成イベントが JPG を `dirty_paths` に入れない。
- 取り込みダイアログのフィルタが `png` だけを含む。
- 既存の PNG 索引・XMP 読み取りのテストが通る。
