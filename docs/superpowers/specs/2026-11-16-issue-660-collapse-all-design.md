# 写真タブ：すべて格納／すべて展開 (#660) 設計

> 状態: モック承認待ち
> モック: `docs/ui-660-collapse-all-mockup.html`
> 対象 Issue: #660

## 目的

写真タブの表示モードがセッションのとき、ギャラリーヘッダーから表示中の全セッションを
まとめて格納・展開できるようにする。個別のセッション見出しを1件ずつ操作する現状の
折りたたみを、一覧全体へ広げる操作として追加する。

## 現状

- ギャラリーヘッダーは `crates/ui/src/ui/gallery.rs::render_header` が描く。
  左に現在月と `N枚 / 総枚数`、右に表示モード切替（時系列／セッション）と
  `並び: 新しい順` を置いている（高さ42 px、子要素の間隔8 px）。
- セッションの格納状態は `crates/ui/src/state/photo_browser.rs` の
  `PhotoBrowser::collapsed_sessions: HashSet<i64>` が保持する。アプリ起動中だけ有効で、
  索引の再読込時は残っているセッションの状態だけを引き継ぐ。
- 格納・展開の操作は `crates/ui/src/app/session.rs::toggle_session_collapsed` が担う。
  セッション見出しの位置をスクロール基準に保ち、通常は `MOTION_BASE` で写真行の高さを
  アニメーションし、reduce motion では即時反映する。
- 未紐付け写真はセッションではなく、撮影日ごとの日付ラベル行として表示する。
  検索結果はセッション表示を持たない。

## 仕様

### ヘッダー

セッション表示のヘッダーは左から次の順に並べる。

1. 現在月と `N枚 / 総枚数`
2. 伸縮スペーサー
3. `すべて格納`
4. `すべて展開`
5. 表示モード切替（時系列／セッション）
6. `並び: 新しい順`（幅が足りる場合のみ）

- 3・4 は `Button::small().ghost()`。高さは表示モード切替のボタンと同じ24 px。
- 3・4 の間隔は2 px、表示モード切替との間隔はヘッダーの8 px。
- タイムライン表示では 3・4 を生成しない。
- セッション表示でヘッダーの内容幅が640 px未満のときは 6 を隠す。
  3・4 と表示モード切替は常に残す。

### ボタンの状態

「表示中のセッション」は、現在のライブラリ索引にある `PhotoIndexEntry.session_id` の
異なる値とする。未紐付け写真は数えない。

| 状態 | すべて格納 | すべて展開 |
|---|---|---|
| 全セッションが展開中 | 有効 | 無効 |
| 一部のセッションが格納済み | 有効 | 有効 |
| 全セッションが格納済み | 無効 | 有効 |
| セッションが0件 | 無効 | 無効 |
| タイムライン表示 | 非表示 | 非表示 |

- 格納済み判定は、表示中のセッションIDのうち `collapsed_sessions` に含まれるものだけを数える。
  索引から消えたIDが `collapsed_sessions` に残っていても、ボタンの状態には影響させない。

### すべて格納

- 表示中のセッションのうち、まだ格納されていないものだけを `collapsed_sessions` に追加する。
- 追加したセッションを写真行が縮む方向へアニメーションする。
- 既に格納済みのセッションのアニメーションは開始しない。
- 対象が0件なら何もしない（ボタンは無効）。

### すべて展開

- 表示中のセッションのうち、格納済みのものを `collapsed_sessions` から削除する。
- 削除したセッションを写真行が伸びる方向へアニメーションする。
- 表示中に存在しないセッションの格納状態は変更しない。
- 対象が0件なら何もしない（ボタンは無効）。

### スクロールとアニメーション

- 操作前に、現在のスクロール位置からビューポート先頭の写真を求める。
- その写真がセッションに属する場合、そのセッションの見出しを基準にする。
  見出しが上に隠れていれば見える位置まで寄せ、操作後も同じ画面位置に保つ。
- 先頭の写真が未紐付け写真の場合、スクロール位置を変更しない。
- 個別操作と同じく、アニメーション中は基準の見出しを追従させる。
- reduce motion が有効ならアニメーションせず、新しい行モデルへ即時切り替える。

## 実装方針

1. `crates/ui/src/state/photo_browser.rs`
   - 表示中のセッション数と格納済み数を返す集計を追加する
     （例: `session_collapse_summary() -> SessionCollapseSummary { total, collapsed }`）。
   - 表示中のセッションだけを対象に格納・展開する
     `collapse_all_displayed_sessions` / `expand_all_displayed_sessions` を追加し、
     実際に変更したIDを返す。
2. `crates/ui/src/app/session.rs`
   - `set_all_sessions_collapsed(collapsed: bool, viewport_height: f32, cx)` を追加する。
   - 既存の `toggle_session_collapsed` と同じ手順で、操作前後のレイアウトを測り、
     先頭セッション見出しのスクロール基準を維持する。
   - 変更したIDだけ `animate_session_collapse` する。reduce motion では
     `settle_session_collapse` する。
3. `crates/ui/src/ui/gallery.rs`
   - `render_header` の右側へ、セッション表示のときだけ一括操作ボタンを追加する。
   - ボタンの有効状態は `session_collapse_summary` から決める。
   - セッション表示で内容幅が640 px未満なら `gallery.sort_newest` を描かない。
4. `crates/i18n/locales/ja.yml` / `en.yml`
   - `session.collapse_all` / `session.expand_all` を追加する。
5. `docs/ui.md`
   - 2.4.2 セッション表示へヘッダーの一括操作、無効条件、スクロール規則、
     狭い幅での並び順の扱いを追記する。

## 非対象

- 個別セッション見出しの折りたたみ操作、見た目、ツールチップ。
- 格納状態の永続化（DB・設定への保存）。
- 検索結果へのセッション表示追加。
- 未紐付け写真の日付ラベル行の折りたたみ。
- キーボードショートカット、コンテキストメニュー、リボンへの導線追加。
- セッションの再構成や、表示対象の絞り込み条件の変更。

## テスト

- 状態の単体テスト:
  - 表示中のセッションだけを数え、索引から消えたIDを無視する。
  - 全展開・一部格納・全格納・セッション0件の各状態で有効判定が正しい。
  - すべて格納は未格納のIDだけを追加し、既存の格納IDを変更しない。
  - すべて展開は表示中の格納IDだけを削除し、表示外のIDを残す。
  - 一括操作後にセッション行モデルが再構築される。
- 回帰確認:
  - 個別見出しの格納・展開、年レールジャンプ、モード切替が従来どおり動く。
  - 格納状態はモードを切り替えてもアプリ起動中は保持される。
  - reduce motion で一括操作が即時反映される。
- 手動確認（`--demo`）:
  - セッション表示で全展開・一部格納・全格納の各状態とボタンの有効／無効。
  - タイムライン表示と検索結果でボタンが出ない。
  - 1280×820 と 1080×700、インスペクタ開閉の各組み合わせでヘッダーが1行に収まる。
  - 未紐付け写真の日付ラベル行が一括操作で変化しない。

ローカル検証は `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、
`cargo test --workspace` とする。

## リスク

- セッション数が多いライブラリで一括アニメーションすると、毎フレーム全写真行の高さを
  再計算する。既存の個別操作と同じ計算量だが、対象が全セッションになるため、
  実機でスクロールとフレーム時間を確認する。必要ならモーション対象を可視範囲へ
  限定するのではなく、まず現行方式のまま計測する。
- 640 px のしきい値はフォントやテーマで実際の文字幅が変わる。実機で
  1080×700 + インスペクタ表示を確認し、必要ならしきい値を調整する。
- スクロール基準の見出しが一括操作で画面外へ出る場合、既存の個別操作と同じく
  見える位置へ寄せる。意図しないジャンプが見つかれば基準写真へ切り替える。
