# 余計な表記の出し分け・集約・部分削除 (#491) 設計

> 状態: 完了（2026-11-12）。docs PR #612、実装 PR #613。
> モック: `docs/ui-491-display-rules-mockup.html`

## 目的

Issue #491 に列挙された「単純削除ではなく、表示条件の変更・集約・部分削除で扱う」
表記を整理する。正常時には出さない、同じ説明を1か所に集約する、注記の一部だけ
残す、0件の内訳を出さない、の4種類で扱う。異常時の表示（停止・失敗・未接続など）
は現行の表記をそのまま使い、文言も変えない。

Issue #491 のうち、ダッシュボード AI カードの状態ラベルは #490 の Q13
（2026-11-10 のモック注釈）で「準備不足・待機中・実行中・失敗をすべて削除する」
と決定済みで、すでに実装されている。本設計では状態ラベルを再追加しない。

## 対象

- ダッシュボードのデーモンカード、AI タグ付けカード
- サイドバーの圧縮キュー状態カード
- 設定のアップデートカード、ライブラリ保存通知、AI タグ付け説明
- タグ別閾値モーダル
- ギャラリーカードと写真インスペクタの圧縮状態バッジ
- ビューア詳細の AI タグ節、写真 AI タグの確率ツールチップ
- 検索の人数（AI）注記、圧縮プロファイル名の注記、取り込み構造の注記
- 空ライブラリ案内、手動圧縮ダイアログ、ページ読み込み失敗、デーモン停止の注記
- `crates/i18n/locales/ja.yml` / `en.yml` の該当キー

## 対象外

- 異常時の表示の文言変更（「停止中」「失敗」「IPC 未接続」などは現行のまま）
- エラーメッセージ、同意・ライセンス文面、破壊的操作の警告文
- 状態ラベルの再追加（#490 Q13 で全削除済み）
- 画面構造・レイアウトの変更（注記を消した結果の整列だけは調整する）
- 新しい設定項目、アイコン、画面の追加

## 方針

1. 正常時に出さない表記は、描画条件を追加して隠す。キーと文言は異常時のために残す
   ものと、不要になるため削除するものを分ける。
2. 同じ説明が複数箇所にある場合は、残す1か所を決め、他方の表示要素とキーを削除する。
3. 注記の一部だけを残す場合は、キーの値を残す部分だけに書き換え、プレースホルダの
   登録を合わせる。
4. 0件の内訳は、0件の項目を描画しない。内訳がすべて0件なら詳細行自体を出さない。
5. i18n キーを削除する場合は ja / en の両カタログから削除し、`tr!` / `tr_args!` の
   呼び出し側も削除する。

## 決定事項

承認時にこの表を確認する。未承認の項目は「推奨」のまま実装しない。

| # | 判断項目 | 推奨案 | 理由 | 状態 |
|---|---|---|---|---|

| Q5 | ギャラリーの状態バッジ | 「圧縮済」だけ出す。「未圧縮」「重複」「圧縮版のみ」は出さない | 状態バッジを圧縮状態の表示に絞る。重複・圧縮版のみはバッジではなく他の情報で扱う | 決定済み（2026-11-12） |
| Q6 | AI カードの件数行 | 0件の項目を隠し、3項目すべて0件なら行ごと隠す | 待機・処理中・失敗の内訳を出す行なので、0件だけの行は情報がない | 決定済み（2026-11-12） |

### 決定（2026-11-12 の Plannotator 回答）

- Q1: 60秒以上で「N秒前」、心拍なしは行を出さない。
- Q2: 未実行・実行中・失敗のすべてで0件を隠す（待機中の内訳にも適用）。
- Q3: 「保存しました。」に統一する。
- Q4: 「更新あり」だけ残す。
- Q5: 圧縮済以外の状態バッジをすべて隠す。
- Q6: 0件の項目を隠し、すべて0件なら行ごと隠す。

## 項目ごとの変更

### 出し分け（正常時は表示しない）

- ダッシュボードの AI タグ付けカード
  - 状態ラベルは #490 で全削除済み。再追加しない。
  - 件数行の「待機」「処理中」「失敗」は0件の項目を出さず、全部0件なら行を出さない。
- ダッシュボードのデーモンカード
  - 状態バッジ「稼働中」は出さない。「停止中」「一時停止中」は出す。
  - 「IPC 接続中」チップは出さない。「IPC 未接続」とエラー付き未接続は出す。
  - 「最終同期」行は心拍が60秒以上古いときだけ出し、値を「N秒前」にする。
    心拍がないときは行を出さない。
- 設定のアップデートカード
  - 状態チップは「更新あり」のときだけ出す。待機・確認中・最新・ダウンロード中・
    準備完了・適用中・エラーでは出さない。エラーはカード本文のメッセージで示す。
- ギャラリーカードと写真インスペクタ
  - 状態バッジは「圧縮済」だけ出す。「未圧縮」「重複」「圧縮版のみ」は出さない。

### 集約（1か所だけ残す）

- タグ別閾値モーダル
  - 適用タイミングの注記はモーダル下部の `settings.ai.thresholds.apply_note` だけ残す。
  - presence カードの「次回のタグ付けから適用」バッジ、`presence_hint`、
    `applies_now` の注記を削除する。presence のリセットボタンは残す。
- AI タグ付けの説明文
  - 連携・自動側の `integrations.ai.hint` だけ残し、設定側の `settings.ai.hint` を削除する。
- サイドバーのキュー空表示
  - 見出し「キューは空です」だけ残し、`sidebar.status.idle.detail` を削除する。
- 手動圧縮ダイアログ
  - `dialog.trash_note` を削除する。元画像の選択肢側の
    `dialog.trash_original_hint`（「圧縮に成功した場合だけOSゴミ箱へ移動します」）だけ残す。

### 部分削除

- `photos.ai.probability_tooltip` はモデル名・生成時刻を除き、確率だけにする。
  `photos.ai.probability` と同じ文面になるため、キーは `photos.ai.probability` に集約し、
  ツールチップ側のキーを削除する。
- ビューア詳細の AI タグ節にあるモデル情報の行（モデル名・バックエンド・生成日時）を削除する。
  `AiMetaView.foot` と、ツールチップ用のモデル・時刻の受け渡しも削除する。
- `compression.name_hint` は文字数だけ残す。
- `search.ai.people_hint` は入力条件だけ残す。
- `gallery.empty` / `app.empty_library` は写真フォルダ設定の案内だけ残す。
- `import.structure.default_hint` は設定間の依存説明だけ残す。
- `settings.library.save_hint` / `saved_rescan` / `saved_restart` は
  `settings.library.saved` に集約する。
- `dashboard.errors.daemon_stopped` は「デーモン停止中です」だけ残す。
- `photos.page_load_failed_body` は失敗したことだけ示す。
- サイドバーの件数内訳と AI カードの件数行は0件の項目を出さない。

## 実装メモ

- `daemon_sync_label` は `Option<String>` を返し、60秒未満と心拍なしは `None` にする。
  60秒は同期表示専用の定数にし、`daemon_liveness` の20秒判定は変えない。
- サイドバー内訳は `sidebar.status.item.running` / `sidebar.status.item.failed` を追加し、
  `" · "` で連結する。既存の headline キーは残す。
- `AiMetaKey` は `photo_id` / `language` / `revision` だけにする。モデル名・生成時刻は
  表示に使わなくなるため、キャッシュキーからも外す。
- `AiTagView` のツールチップは常に `photos.ai.probability` を使う。
- `UpdatePhase::badge` は `Option` を返し、`Available` のときだけ `Some` にする。
  `update.phase.idle` だけでなく、チップでしか使っていない `update.phase.checking` /
  `up_to_date` / `downloading` / `ready` / `applying` / `error` も削除する。
- ギャラリーカードの状態バッジは `compressed` のときだけ描画する。`duplicate` と
  `replaced` はバッジ描画に使わなくなるため、カード内の変数と
  `gallery.badge.duplicate` / `gallery.badge.compressed_only` を削除する。
- 0件非表示は、要素を組み立ててから条件付きで `child` する。空の詳細行は
  `CardStatus.detail` を空文字にして既存の描画条件で消す。

## リスク

- 正常時に状態チップを消すため、初見では状態が分かりにくくなる可能性がある。
  ただし、件数・ジョブ一覧・操作ボタン・停止/未接続の異常表示は残す。
- 最終同期の60秒はハートビート間隔（10秒）に依存する。間隔を変える場合は定数も見直す。
- `AiMetaKey` からモデル名・時刻を外しても、表示に使わないためキャッシュの正しさは変わらない。
