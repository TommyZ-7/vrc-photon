ISSUE #521 UI REVIEW / CARD SEPARATORS

設定・連携カードに項目ごとの区切り線を追加

設定画面と「連携・自動」画面の各カードに、項目間の薄い区切り線を入れます。 カードの内側余白・項目構成・既存のグループ境界線は維持し、線の追加だけを行います。 このページは実装前のモックです。

06

実装メモ

承認後に実装する内容。データ・保存処理・文言・カード幅は変更しません。

共通ヘルパー

  • components.rs に区切り線ヘルパーを追加し、全カードで同じ見た目にする。
  • h(px(1.)).w_full().bg(rgba(p.line_soft))。カードの子要素として挿入するため、左右は自動的に 14px パディングの内側になる。
  • カードの p(px(14.)) と gap(px(12.)) は変更しない。

挿入ルール

  • 各カードの最上位の子要素の間に 1 本ずつ。最後の子要素の後には挿入しない。
  • 条件付き要素（警告・エラー・ダウンロード進捗など）は、表示されている場合のみ項目として数える。
  • 表示カードの既存 div().h(px(1.)).bg(...) は残し、その境界には新しい線を追加しない。

確認範囲

  • 設定画面: 表示・起動・サムネイル・ログを含む全カードをスクロールして確認。
  • 連携・自動画面: Discord / 自動圧縮 / AI タグ付け / クリップボード / 送信履歴の各セクション。
  • ライトテーマでも line_soft が背景から浮きすぎないことを確認。

変更しないもの

  • カードの並び順・幅・角丸・背景・影・パディング・ギャップ。
  • 設定値、保存処理、表示条件、文言、アイコン、スイッチの動作。
  • マスター一覧、履歴行、プロファイル行、モーダルの既存区切り。

このモックで実装を進めてよいか確認してください

特に次の 3 点を確認してください。

  1. カード見出しの下にも線を入れる（見出しを 1 項目として扱う）。
  2. 表示カードの既存グループ境界線は 1 本のまま残す（トグル群とスライダー群の間に新しい線を重ねない）。
  3. 左側のマスター一覧、履歴行、プロファイル行の区切りは対象外とする。

修正がある場合は、線の位置・本数・濃さ（line_soft より薄くする等）を指定してください。承認後に実装ブランチを作成し、各画面のスクリーンショットで回帰確認します。
