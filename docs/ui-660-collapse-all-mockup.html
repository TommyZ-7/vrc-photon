動作とスコープ

実装メモ

対象になるセッション

  • 現在のライブラリ索引にある session_id 付きの写真を、セッション単位で数える。
  • セッションに属さない写真の日付ラベル行は対象外。
  • 検索結果はセッション表示を持たないため対象外。
  • 表示中に存在しないセッションの格納状態は変更しない。

一括操作の挙動

  • すべて格納: 展開中のセッションだけを新たに格納する。既に格納済みのものは触らない。
  • すべて展開: 格納済みのセッションをすべて展開する。
  • 個別の格納と同じくアニメーションし、reduce motion では即時反映。
  • 連続クリックしても二重にアニメーションを開始しない。

スクロール位置

  • ビューポート先頭のセッション見出しを基準に、操作前後で同じ位置に保つ。
  • 見出しが一部隠れている場合は、見える位置まで寄せる（既存の個別操作と同じ）。
  • 先頭が未紐付け写真の場合は、現在のスクロール位置を維持する。
実装上の前提
  • 格納状態は既存の PhotoBrowser.collapsed_sessions をそのまま使い、新しい設定項目や DB 列は追加しない。
  • 翻訳キーは session.collapse_all / session.expand_all を ja / en に追加する。
  • ボタンの無効判定は「表示中のセッション数」と「そのうち格納済みの数」を比較して行う。
  • タイムライン表示・検索結果ではヘッダーに要素を追加しない（既存レイアウトを維持）。
