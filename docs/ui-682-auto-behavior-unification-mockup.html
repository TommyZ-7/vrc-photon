#682settings unification

自動動作の設定を3機能で統一する

自動圧縮・Discord 自動送信・AI 自動タグ付けの自動動作を 「しない／即時／待機」の3値に、対象範囲を 「有効化以降の新規のみ／既存の未処理分も含める」の2値に揃える。 対象範囲は一括処理ボタンにだけ適用し、自動投入は新規索引写真だけを対象にする。

4. Discord の一括送信確認

対象件数と非公開インスタンスの注意

「未送信を一括送信」を押したときだけ出す。0件ならダイアログを出さず、 「送信対象の未送信写真はありません。」をトーストで出す。OK で既存の同意が 未記録なら記録し、pending で積む。

既存の未送信写真 128 件 を Discord へ送信します。 Webhook の投稿先を確認してください。
非公開インスタンスで撮影した写真も含まれます。

5. 判断と挙動の確認

実装前に合意する範囲
項目決定補足
自動動作しない / 即時 / 待機3機能で同じ `AutoMode`。圧縮のマスタースイッチは廃止。
対象範囲有効化以降の新規のみ / 既存の未処理分も含める一括処理ボタンにだけ適用。自動投入は新規索引写真だけ。
既存分の実行手動ボタンのみ初回フルスキャンでは3機能とも自動投入しない。
「新規」の基準ライブラリへの追加以降`photos.created_at`。Discord の撮影時刻カットオフは廃止。
Discord の対象未送信の全写真送信成功なし・アクティブ送信なし・削除中でない。失敗・取消は含む。
Discord の確認件数付きダイアログ0件は情報トースト。OK で同意未記録なら記録。
AI 即時準備完了時のみ積む未準備では積まない。待機は未準備でも waiting で積む。
「しない」の一括処理無効圧縮・AI は「待機」を選ぶと使える。Discord はボタンを出さない。
ジョブ基盤変更しないテーブル・状態・ワーカー・再試行は統合しない。

レビュー時の確認ポイント
  • 3カードと3セットアップページで「自動動作」「対象範囲」の順序と文言が同じか。
  • 自動圧縮カードからマスタースイッチが消え、圧縮設定が常に編集できるか。
  • 「しない」のとき、圧縮・AI の一括処理が無効で理由が出ているか。
  • Discord の一括送信が未送信だけを対象にし、件数確認を出しているか。
  • 初回フルスキャンでは自動投入せず、取り込み・監視・2回目以降のスキャンでは自動投入するか。
  • 旧設定の移行と、`discord_auto_since` 廃止の挙動変化に納得できるか。
