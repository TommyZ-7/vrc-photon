挙動

既存の写真操作・年レール・設定との関係

モード切替

  • Photos 画面のギャラリーヘッダーに「時系列 / セッション」を置く。
  • 既定は時系列。切替時は、いま見ている先頭写真が新しいモードでも同じ位置に残るようにスクロールを合わせる。
  • 選択はアプリ設定に保存し、再起動後も復元する。
  • 検索結果画面には適用しない（初版）。

グルーピング

  • photo_context.session_id が同じ写真の連続区間を 1 セッションとしてまとめる。
  • session_id のない写真は、時系列の位置のまま日付ラベルを付ける。時刻が重なるセッションへは寄せない。
  • セッションの写真枚数・同席者は sessions / session_players から取得する。
  • 見出しの取得は表示範囲のページ単位。読み込み中は見出しの高さを変えない。

写真操作・年レール

  • 写真カードの選択・Shift 範囲選択・右クリックメニュー・ダブルクリックの詳細表示は時系列モードと共通。
  • 年レールはセッションモードでも表示し、年クリックでその年の最初の写真を含む行へ移動する。
  • カードサイズ・ワールド名・日時・サイズの表示設定は両モードで共通。
  • 見出しの折りたたみは表示だけの状態で、写真の選択やタグには影響しない。

決定事項

2026-11-09 にすべて推奨案どおりで確定

1. 検索結果への適用

検索条件で切り取られた集合ではセッションの区切りが不完全になりやすい。初版は Photos 画面のみとし、検索結果は時系列のままにする。

決定: Photos のみ

2. 見出しの折りたたみ

長いセッションを飛ばす用途が明確なため初版に含める。状態は保存せず、画面を離れると展開に戻る。

決定: 初版に含める

3. モードの保持

Photos の表示設定としてアプリ設定に保存し、再起動後もセッションモードで開く。設定画面には項目を追加しない。

決定: 保存する

4. XMP のみの写真の帰属

photo_context.session_id の有無を厳密に使い、撮影時刻が重なるセッションへは寄せない。誤った帰属を作らない。

決定: 寄せない

5. 年レール

時系列モードと同じ年レールをセッションモードでも表示し、見出し行を含む行モデルに合わせて位置を計算する。

決定: 表示する

6. セッションが分断された場合

同じ session_id の写真が未紐付け写真などで分断された場合は、分断ごとに同じ見出しを繰り返さず、最初の見出しの後は写真行だけを続ける。実データでは通常発生しない。

決定: 見出しは最初の1回

対象外

初版で扱わないもの

セッションの編集

結合・分割・写真の割当て変更は行わない。sessions テーブルの内容をそのまま表示する。

セッション単位の操作

まとめて圧縮・送信・タグ付けは行わない。写真単位の既存操作のみ。

ログのない期間

セッションを再構成しない。session_id のない写真は日付ラベル付きの時系列として表示する。
