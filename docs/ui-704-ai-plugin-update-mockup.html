#704AI plugin update notice · display only

AIプラグインの更新通知

本体の更新確認で取得した latest.json の ai_plugin と、導入済みプラグインの版を比較する。 新しい版があり、かつ現在の本体版が host_version_min 以上なら、設定画面の AI タグ付けカードに 表示だけの通知を出す。ダウンロード・自動更新・追加通信は行わない。導入済みの状態では .vpp 取込ボタンを「プラグインを更新」に切り替える。

更新情報latest.json の任意欄 ai_plugin
通知条件新バージョン + 本体互換
今回の値v0.5.1 / host 0.14.4
状態承認待ち

承認ポイント

実装前に確認する判断
Q1 · 情報源

latest.json の任意欄だけを使う

プラグイン配布サーバーへの問い合わせや GitHub API は追加しない。本体の更新確認で取得した署名済みマニフェストを再利用する。

追加通信なし
Q2 · 通知条件

新しい版 + 本体が対応

ai_plugin.version がアクティブな導入版より新しく、ai_plugin.host_version_min が現在の本体版以下であること。両方を満たすときだけ出す。

表示のみ
Q3 · 再起動後

updates 配下のキャッシュを使う

更新確認は24時間に1回。取得した ai_plugin を updates/ai-plugin.json に保存し、確認が走らない起動でも通知できる。

通信なしで復元
Q4 · ボタン文言

導入済みは「プラグインを更新」

未導入は現行の「プラグイン (.vpp) を取り込む」のまま。導入済みは Ready だけでなく、モデル未取得などアクティブな導入がある全状態で切り替える。

3. 導入済み · モデル未取得 · 更新あり

Ready 以外でも通知する

アクティブな導入がある限り、モデルの準備状況にかかわらず通知と文言切替を行う。モデル未取得時は通知の下に モデル取得の導線が続くが、プラグイン更新の通知とは独立している。

4. 導入済み · 更新なし

通知を出さない条件

フィードの ai_plugin.version が導入版以下、または host_version_min が現在の本体版より新しい場合は通知を出さない。 後者では「本体を更新してください」などの代替表示をせず、現状のままにする。通知がなくても、導入済みなら .vpp ボタンは「プラグインを更新」のまま。

本体互換なし: 例としてフィードが v0.6.0 / host_version_min 0.15.0、本体が 0.14.4 の場合も通知しない。

回帰確認の対象

比較対象: アクティブな導入版のみ。別 variant に新しい版があっても、使用中でなければ通知しない。

キャッシュ: 最後に取得した ai_plugin を updates/ai-plugin.json に保存。フィードから欄が消えたら削除する。壊れたキャッシュは無視する。

不正な値: 非 semver・型違い・キー欠落の ai_plugin は通知だけを出さず、本体の更新確認は継続する。

  • カードのタイトル・メタ情報・variant 一覧・モデル情報の並び
  • モデルのダウンロード、取込、削除、再確認の動作
  • プラグインの取込ダイアログとインストール処理
  • タグ別閾値、アンインストール、ダッシュボードの AI カード
  • 本体の更新確認・更新通知・更新適用
  • プラグインのダウンロード・自動更新・追加の通信は追加しない

翻訳: settings.ai.update（プラグインを更新 / Update plugin）と settings.ai.update_available（新しいプラグイン版 v%{version} があります）を追加する。

実装前: このモックの承認後に UI 実装を開始する。update / release-tool の非 UI 部分は承認待ちの間に先行してよい。

承認時にお願いしたいこと
  • 通知は「バージョン」行の直下に、アクセント色・10 px・クリック不可の1行で置く。
  • 通知条件は「新バージョン」かつ「host_version_min が本体版以下」の両方。片方だけでは出さない。
  • 導入済みの全状態で .vpp ボタンを「プラグインを更新」にし、未導入は現行文言のままにする。
  • プラグインのダウンロード・自動更新・追加通信は行わない。通知は表示のみ。
