挙動

既存の検索条件・検索ボタンはそのまま

表示条件

  • 入力が空、または空白のみなら閉じる。
  • 部分一致の候補が0件なら何も表示しない。
  • フォーカス時に既存の入力があれば再表示する。
  • Esc で閉じた後は、次の文字入力まで再表示しない。

キーボード / マウス

  • ↑↓ 候補の選択を移動（端で止まる）。
  • Enter 選択中の正式名を入力欄へ反映。
  • Esc 候補を閉じる。入力値は保持。
  • 行のクリックでも確定。外側クリックで閉じる。

選択後

  • 入力欄の値だけを正式名へ置き換える。
  • 検索は自動実行しない（既存の「検索」ボタンのまま）。
  • フォーカスは入力欄に残し、続けて編集できる。
  • 候補リストは閉じる。
