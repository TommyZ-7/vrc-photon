ステップを直接選ぶと、モーダル内の遷移アニメーションを確認できます。テーマと言語はモーダル内で切り替えられます。

01フローと操作

  • ようこそ → 写真フォルダ → 自動化 → 見た目 → 完了 の5ステップ。モーダルは1枚だけで、中身だけを遷移する。
  • 上部の戻るボタンと ←、フッターの primary と Enter / → で移動する。最終ステップの primary は「VRC PhotoN をはじめる」。
  • 完了画面のサマリー行をクリックすると、その設定ステップへ戻る。修正してから開始できる。
  • 右上の「あとで」と Esc は、フッター上に確認帯を出す。別モーダルは重ねない。閉じることは完了と同じ扱いで、次回起動時には表示しない。
  • スクリムのクリックでは閉じない。初回設定の誤操作を防ぐため、既存の取り込み・圧縮ダイアログとはここだけ挙動を変える。
  • 完了・閉じた後は通常のメイン画面へ戻り、トーストで「次回は表示しない」ことを伝える。

02モーション

  • モーダル表示: 460 ms。背景スクリム: 260 ms。不透明度・14 px の持ち上げ・0.985 の縮小を同時に動かす。
  • ステップ遷移: 入り 340 ms / 出 200 ms。進むときは右から +28 px、戻るときは左から -28 px。出る側は 18 px 反対方向へ抜ける。
  • 進捗線: 480 ms。テーマ切替: 320 ms。チェック描画: 円 620 ms + チェック 320 ms（460 ms 遅延）。
  • イージングは実装の ease_motion に合わせた cubic-bezier(0.22, 0.8, 0.24, 1)。移動量は SCREEN_SLIDE の 14 px より少し大きくし、ステップ感を出す。
  • 「アニメーションを減らす」が ON のときは、移動をなくして表示切替だけにする。設定値 ui_reduce_motion をそのまま使う。
  • モーダルは 780×640 を上限に、ウィンドウ内容高 - 48 px に収める。低いときは本文だけをスクロールし、ヘッダーとフッターは固定する。

03初回判定と永続化

完了状態は設定 JSON に混ぜず、app_settings の別キー setup_completed_at に Unix 秒で持つ。 開始状態も setup_started_at として別に保存する。既存の設定 JSON に新しいフィールドを足すと、 「フィールドがない＝未完了」と「移行前の既存ユーザー」を区別できないため。

  • 表示する 完了キーなし。開始キーがあれば、設定行ができていても中断したセットアップとして再表示する。
  • 表示しない 完了キーあり。開始キーがなく、設定行または写真 / revision がある場合は、移行時に完了キーを書き込んで既存ユーザーとして扱う。
  • 新規 開始・完了のどちらもなく、設定行・写真・revision も空なら新規インストール。表示前に開始キーを書き込む。
  • 完了・閉じるのどちらでも、その場で setup_completed_at を保存する。途中で終了した場合は開始キーだけが残り、次回また表示する。
  • 写真フォルダ・自動化・テーマは選択時に即時保存する。開始キーがあるので、途中で設定行ができても既存ユーザーと誤判定しない。
  • 「あとで」で閉じた場合も再表示しない。設定画面から各項目は変更できるが、セットアップを再表示する導線はこの issue の範囲外とする。

04Windows 初期セットアップとの対応

  • 左揃えの大きな見出し、短い説明、1ページ1判断の構成を踏襲する。カードを並べすぎず、余白で区切る。
  • 左上に戻る、右下に primary。言語とスキップは右上に小さく置き、主操作と競合させない。
  • 背景にはテーマ色の淡いブルームを置く。Windows の壁紙のような雰囲気を、アプリの不透明パネルの中で再現する。
  • 進捗は Windows のような「点だけ」ではなく、上部2 px の線と 01 / 05 を併用する。何ステップ残っているかを明確にする。
  • 完了は大きなチェックの描画で締める。最後に「準備しています…」を短く挟んでからモーダルを閉じ、メイン画面へ渡す。

05実装メモ

  • 文言はすべて setup.* として ja.yml / en.yml に登録する。モック内の英語切替は、文言の長さと折返しを確認するためのもの。
  • キー例: setup.welcome.title, setup.photos.title, setup.auto.title, setup.look.title, setup.done.title, setup.action.next, setup.action.start, setup.skip.title。
  • フォルダ変更は既存の OS フォルダ選択ダイアログを使う。モックではトーストで代替している。
  • role="dialog" / aria-modal="true"、フォーカストラップ、スイッチの role="switch" と aria-checked、選択中テーマの aria-checked を付ける。
  • テーマは選択時に ui_theme_main / ui_theme_accent へ即時反映する。モーダルを含む全画面が同じパレットに従う。
  • 新しい画像アセットは増やさない。既存のアプリアイコン、アイコンセット、パレットから構成する。

06このモックで固定する案

表示内容は「写真フォルダ・自動化・テーマ」の3点に絞る。取り込み先、AI タグ付け、Discord 連携は初回には出さず、既定値のまま通常画面で変更する。 完了も閉じるも同じ完了状態とし、次回起動時は表示しない。

  • 決定案 単一モーダル / 5ステップ / 右上に言語とスキップ / 閉じる前にインライン確認。
  • 要承認 ステップ構成、閉じる＝完了の扱い、既存ユーザーの判定条件。
  • 範囲外 設定画面からのセットアップ再表示、取り込み先の選択、連携の初期設定。
