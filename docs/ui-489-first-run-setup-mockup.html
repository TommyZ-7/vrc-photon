VRC PhotoN 初回セットアップ モック

デザイン画像は方向性として扱い、設定項目は実装の設定画面（docs/ui.md §2.9 / §2.10）と AppSettings に合わせたレビュー用モックです。各フレームは 1280×820。 上の 46px は最小タイトルバーで、その下の 774px がデザイン画像と同じ領域です。

設定画面との対応
  • 2 起動 → 設定 > 起動
  • 3 フォルダ → 設定 > ライブラリ
  • 4 表示 → 設定 > 表示 / サムネイル
  • 5 Discord → 連携・自動 > Discord 連携
  • 6 自動圧縮 → 連携・自動 > 自動圧縮
  • 7 テーマ → 設定 > テーマ
  • 8 AI → 紹介と表示プレビュー（設定は「設定 > AIタグ付け」）
初回に必要な項目だけを抜粋 自動送信・送信履歴・Discord 圧縮、圧縮の画質・リサイズ、AI のバックエンド・閾値・variant 管理、 ワールド名解決、最大FPS、自動更新、サムネイルキャッシュ、クリップボードは設定画面に残します。 フォルダの「変更」は初回用の追加（設定画面は直接入力）です。
状態は一例 起動は 自動起動ON / トレイON / アニメーションOFF、表示は4項目ON・14px・13px・384×216、 自動圧縮は WebP ロスレス、テーマは既定のチャコール＋スカイ。Discord は初期OFFで、下部項目はグレーアウトします（スイッチで切替）。 AI は設定ではなく、紹介文とタグ表示のプレビューです。表示ページ右のプレビューは、スイッチ・スライダー・解像度の操作に追従します。 右上の×は削除（Escで閉じる）。ページの次へ / 戻るは横スライド 180ms です。

AIタグ付けプラグインは BOOTH で購入できます。
