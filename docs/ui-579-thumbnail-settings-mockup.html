操作と反映

  • 解像度を選ぶと即座に保存し、旧キャッシュを全削除する。
  • 表示中のサムネイルは新しい配列で作り直す。
  • 再生成は表示された写真から順に行う。全件を一括生成はしない。
  • 数値は保存形式の変更に伴う一例。実測値は実装後に記録する。
