ISSUE #487 UI MOCK / PROPOSAL

写真グリッドの間隔とカード角丸

設定画面の 「表示（ライブラリ・検索）」 に2つのスライダーを追加し、Photos の時系列表示・セッション別表示と検索結果へ再起動なしで反映します。間隔は横方向と縦方向の両方に、角丸は写真カードと内側画像に適用します。

プレビューは実際の描画に合わせた簡略版です。列数はウィンドウ幅と間隔から再計算され、間隔を広げると列数が減ることがあります。Photos のセッション別表示と検索結果も同じ値を使います。

値の比較 端の見え方

0 px でもカードの境界は1 px線で判別できます。角丸0では内側画像も0になります。

間隔 0 px

カードが接する。列数は最大。

間隔 14 px（既定）

現在の見た目を維持する。

間隔 32 px

余白を広く取る。列数が減ることがある。

角丸 0 px

カードも内側画像も直角。

角丸 13 px（既定）

現在の見た目を維持する。内側画像は12 px。

角丸 24 px

丸みを強調する。内側画像は23 px。

決定事項

実装前に確認する項目です。

入力方式スライダー＋現在値表示。既存のサムネイル画質と同じ操作感。
配置既存の「表示（ライブラリ・検索）」カード内、4スイッチの下。
縦方向横・縦の両方に同じ値を適用。セッション見出し行の間隔も連動。
保存ドラッグ中は即時反映、指を離した時に保存。DB書き込みは1回。
反映範囲Photos の時系列・セッション別と検索結果。写真カード以外の角丸は変えない。
範囲外の値読み込み時・保存時に範囲内へ丸める。既定は 14 px / 13 px。
