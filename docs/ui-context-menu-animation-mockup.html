仕様と確認ポイント

アニメーションは開くときだけ。閉じる・項目構成・レイアウト・文言は変えません。

100–150ms の範囲に収める

モーション仕様

対象メインメニューと圧縮サブメニュー（右クリック／Menu・Shift+F10 の双方）
時間A: 100ms / B: 120ms（推奨） / 現行: 0ms
透明度0 → 1（フェードイン）
移動量B のみ translateY(-4px) → 0。A は移動なし
イージングease_motion（cubic-bezier(.22,.8,.24,1)）
閉じる即時（現行どおり 0ms）
縮小設定「アニメーションを減らす」有効時は即時表示
画面端表示位置の調整後にアニメーション。位置計算は変更しない
連続開閉開くたびにタイムラインをリセット。残像・状態不整合なし

確認ポイント

  • 右クリックとキーボードの双方で同じ動きになる。
  • 圧縮サブメニューもメインと同じ時間・曲線で開く。
  • アニメーション中でも Esc・外側クリック・フォーカス喪失で閉じる。
  • 画面端で上・左方向に位置調整されても、動きの起点が破綻しない。
  • 素早く開閉を繰り返しても、途中の不透明度や位置が残らない。
  • 既存のメニュー関連テストが通る（項目構成は不変）。
スケールは使用しません。等倍で描いたテキストの輪郭を保ち、画面端でも起点の補正が不要なためです。
