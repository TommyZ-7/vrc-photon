実装メモ

今回変えないもの

タブとドット

タブは「自動圧縮 / Discord / AIタグ」の3項目。有効な機能だけを表示し、選択中のタブが無効なら先頭へフォールバックする。右上の4 pxドットは実行中・実行待ち・待機のみで、失敗では付かない。

開始と一時停止

待機があるときは「未実行を開始」、ないときは「キューを開く」。一時停止中は開始ボタンを無効にし、フッターに「一時停止中」を表示する。押したときの動作は現行の release_waiting_queue のまま。

全体の区切り

キューが空の状態から最初のジョブが入った時点で全体を開始する。途中で追加されたジョブは同じ全体の未完了数に加算し、キューが空になった後の最初のジョブから完了数を0に戻す。失敗・取消はどちらの件数にも入れない。
