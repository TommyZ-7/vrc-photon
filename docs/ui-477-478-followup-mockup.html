動き

  • 展開 → 折りたたみ: 写真行の高さ 100% → 0、不透明度 1 → 0。
  • 折りたたみ → 展開: 0 → 100%、0 → 1。
  • イージングは既存の ease_motion、時間は MOTION_BASE（220 ms）。
  • 見出しの矢印はクリック直後に目標状態へ切り替える。

スクロールと状態

  • 見出しの位置は動かさない。下の行だけが縮む / 伸びる。
  • 連続クリックは現在の途中値から目標へ向き直す（跳ばない）。
  • 複数セッションを同時に動かせる。
  • 画面を離れる・索引を再読込すると即時に確定する。

設定への追従

  • ui_max_fps をアニメーションの with_max_fps に渡す。0 / リフレッシュ同等は上限なし。
  • reduce motion が有効なら 1 フレームで即時切替。
  • キーボードで隠れた写真へ移動したときの自動展開は、選択を見せるため即時（Q5）。

承認前に確認したいこと

推奨案でモックを作っています。番号で回答してください。

Q1. #477 の一覧の面

一覧全体を 1 枚のカードにする（推奨）。行ごとにカードを分ける案より、詳細ペインのカードと視線が揃い、行間も詰まって見える。

推奨: 一覧全体を 1 枚のカード

Q2. #477 の一覧幅

252 px のまま、内側に 8 px の余白を入れる（推奨）。外部幅を変えないので、既存のスタック閾値 888 px に影響しない。

推奨: 252 px + 8 px inset

Q3. #478 の時間

既存の画面遷移と同じ MOTION_BASE 220 ms（推奨）。300 ms は大きなグループではゆったりするが、連続操作には少し遅い。

推奨: 220 ms / ease_motion

Q4. #478 の見た目

高さと不透明度を同時に動かす（推奨）。高さだけだと、写真の下側が急に切れて見える。

推奨: 高さ + フェード

Q5. キーボード移動時の展開

隠れた写真へ選択が移ったときは即時展開する（推奨）。アニメーション中にスクロールすると、選択位置が定まらないため。

推奨: 自動展開は即時

Q6. 複数セッション

同時に折りたたみ・展開できる（推奨）。各セッションの途中値から独立して目標へ向かう。最後の 1 つが終わるまでフレームを駆動する。

推奨: 独立して同時に動かす
