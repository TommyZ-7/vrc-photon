ISSUE #491 UI COPY / VISIBILITY

余計な表記の出し分け・集約・部分削除

正常時には出さない、同じ説明は1か所に集約する、注記の一部だけ残す、0件の内訳を出さない。 異常時の表示（停止・失敗・未接続）は現行の文言のまま残します。 #490 Q13 で全削除済みの AI カード状態ラベルは再追加しません。

承認ポイント

判断が必要な6項目
Q1

最終同期を出す条件

心拍が60秒以上古いときだけ「N秒前」を出す。心拍がないときは行を出さない。systemd は「N秒前 · systemd」。

決定: 60秒閾値 / 心拍なしは行を出さない 決定済み
Q2

サイドバーの0件内訳

未実行・実行中・失敗の内訳すべてで0件を出さない。内訳が空なら詳細行を出さない。

代替: running.detail / failed.detail だけを対象にする 推奨
Q3

ライブラリ保存通知

成功時は既存の「保存しました。」に統一。save_hint / saved_rescan / saved_restart は削除。

代替: 3キーを残して付記だけ削る 推奨
Q4

アップデートの状態チップ

「更新あり」のときだけ出す。待機・確認中・最新・ダウンロード中・準備完了・適用中・エラーでは出さない。

決定: 更新ありだけ残す。エラーは本文で示す 決定済み
Q5

ギャラリーの状態バッジ

「圧縮済」だけ出す。「未圧縮」「重複」「圧縮版のみ」は出さない。

決定: 圧縮済以外の状態バッジをすべて隠す 決定済み
Q6

AI カードの件数行

0件の項目を隠し、3項目すべて0件なら行ごと隠す。

代替: 0件でもラベルだけ残す 推奨
