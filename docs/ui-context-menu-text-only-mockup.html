1左アイコン列をなくす

メニュー全体にアイコンが1つもないため、gpui-kit は左アイコン用の余白を確保しません。全ラベルがメニューの左パディングから始まります（変更後パネルの緑の破線）。

2項目の中身は変えない

区切り線、項目順、文言、無効条件、ショートカット表示は現状のままです。複数選択時の「（1枚のみ）」も維持します。

3サブメニューの › は残す

圧縮の › は項目アイコンではなく、サブメニューがあることを示す手掛かりです。今回の提案では削除せず、開閉動作も維持します。

実装メモ

  • 対象は crates/ui/src/app/context_menu.rs（Issue の ui/actions.rs はリファクタ前の参照）。
  • PopupMenuItem::icon(...) を全項目から削除し、submenu_with_icon(Some(...), ...) を submenu(...) に置換。
  • メニュー幅は既存の min_w(px(252.)) を維持し、レイアウトの跳ねを避ける。
  • 左アイコンが無くなることで has_left_icon が false になり、テキスト開始位置が自動的に揃う。

受け入れ条件

  • 単一選択・複数選択の全項目からアイコンが消えている
  • 圧縮サブメニューの開閉と各項目の操作が従来どおり
  • 項目の構成・順序・文言・有効条件・動作が変わらない
  • 既存のメニュー関連テストが通る
