#737UI mockup · developer card

設定画面の下部に開発者情報カードを追加

設定画面の最下部、「設定を再読込」の下に1枚のカードを置く。左に丸型の開発者画像と名前、 縦の区切り線を挟んだ右にバージョン / ライセンス / リポジトリ / Xを 小ラベル＋値で縦に並べる。リポジトリと X の値はクリックでブラウザを開く。

承認ポイント

実装前に確認する決定
Q1 · 位置

「設定を再読込」の直下

設定カード列の最末尾に置く。再読込ボタンとの間隔は、他のカードと同じ 12 px のギャップを保つ。

末尾に固定
Q2 · 構成

見出しなしの左右2列

カード見出しは置かない。左に丸型画像と名前、縦区切り線、右に4項目。各項目は小ラベル＋値で、項目間に1 pxの区切り線を入れる。

issue の構成どおり
Q3 · リンク

値だけをリンクにする

リポジトリと X は値の文字だけをアクセント色にし、ホバーで下線を出す。クリックで既定のブラウザを開く。ラベルはリンクにしない。

値だけクリック可能
Q4 · 画像

64 px の丸型

~/devinfo-avatar.jpg（400×399）をアセットとして同梱し、64 px の円形に切り抜く。画像の比率は Cover で維持する。

64 px / Cover

リンクの動作

リポジトリは https://github.com/TommyZ-7/vrc-photon、X は https://x.com/TommyZ794685 を既定のブラウザで開く。既存の open_path を使い、失敗時はトーストで知らせる。

バージョンの取得元

vrc_photon_update::CURRENT_VERSION に v を付けて表示する。設定画面のアップデートカードと同じ値を参照し、別の定数を増やさない。

実装メモ

今回変えないもの

画像の同梱

~/devinfo-avatar.jpg を crates/ui/assets/devinfo-avatar.jpg としてコピーし、include_bytes! で埋め込む。実行時に外部ファイルを読まない。

既存カードとの整合

新しいカード部品は増やさず、設定画面の既存 glass_panel と card_divider の組み合わせで作る。角丸は既存カードと同じ17 px。

スコープ外

ライセンス全文へのリンク、リポジトリのスター数や最終更新、X のタイムライン埋め込み、画像の変更機能は置かない。クリックできるのはリポジトリと X の値だけ。
