  • 押下と離しが同じ要素で成立するクリック条件を実装時に確認する。

Q8-1. 三角の見た目とヒット領域

三角の背景・枠は消し、三角のみを見せる。ヒット領域は 36×36 px を確保する。32 px は最低ライン、40 px は見出しに対して大きすぎる。

推奨: 36 × 36 px / 三角のみ

Q8-2. クリック対象

カード全体を折りたたみ対象にし、右端の三角は残す。三角側で stop_propagation() して二重発火を防ぐ。カード全体に hover 背景とポインタカーソルを付ける。

推奨: カード全体 + 三角

Q8-3. ドラッグ誤作動

カード上から始まるドラッグスクロールで折りたたみが発火しないよう、押下と離しが同じ要素で成立するクリック条件を実装時に確認する。必要なら押下位置からの移動距離でガードする。

推奨: 同一要素のクリックのみ

年レールで 2 区間目の写真へジャンプしたときは、セッションを展開し、継続見出しが先頭に来る。

行モデル

  • 最初の区間はフル見出し。
  • 2 区間目以降は、展開時だけ継続見出し。
  • 折りたたみ時は継続見出しを出さない。
  • 年レールのアンカーは各区間の先頭行に合わせる。

操作

  • 継続見出しはクリック対象にしない。
  • 折りたたみは最初のフル見出しカード（とその三角）だけ。
  • 写真の選択・右クリック・ダブルクリックは従来どおり。

見た目

  • 高さ 44 px、左に細いアクセント線。
  • ワールド名＋「続き」バッジ＋区間枚数。
  • フル見出しより弱い面にして、主見出しを邪魔しない。

Q9-1. 継続表示の案

A は情報量が多いが縦に重い。C は通常時が軽いが、通り過ぎると文脈が消える。B は 44 px でセッション名を保ち、折りたたみも 1 つに集約できる。

推奨: B. コンパクトな継続見出し

Q9-2. 折りたたみ時の継続見出し

折りたたみ中は写真行も継続見出しも隠し、最初のフル見出しだけを残す。状態はセッション単位で 1 つ。

推奨: 継続見出しも隠す

Q9-3. 継続見出しの操作

クリック・折りたたみ操作は付けない。年レールのジャンプは継続見出しの位置へ着地する。

推奨: 操作なし / アンカーのみ

Q9-4. 区間枚数の表記

フル見出しの「写真 3 枚」はセッション全体、継続見出しはその区間の枚数を示す。誤解を避けるため「1枚」のように短くする。

推奨: 区間枚数のみ

実装メモ
  • #495 は Phase 3（#492 / #500 と同時）に実装する。カード全体をクリック対象にし、三角は背景・枠を消して 36×36 px のヒット領域だけを持たせる。stop_propagation() でカード側と分離する。SESSION_HEADER_CONTROL_INSET = 50 px で月ピルの左へ退避する。
  • #499 は Phase 5 の単独 PR。承認された案に合わせて SessionRowKind::Continuation、高さ 44 px、i18n キーを決める。
  • 折りたたみ状態はアプリ起動中だけ保持し、再起動では保存しない。索引再読込時は残存セッションだけ引き継ぐ。
