削除後に判断が必要な点
Q1 · 件数の代替表示

ヘッダーには何も足さない

未完了ジョブ数はダッシュボードの統計カードとサイドバーの圧縮バッジ、待機・失敗はキューの各行で確認できる。ヘッダーには件数も説明文も追加しない。

Issue 指定どおり
Q2 · 翻訳キー

未使用キーを削除する

compression.queue.active / waiting / auto_keep / auto_replace / failed は他の画面で使っていないため、ja / en と placeholder テスト台帳から削除する。Discord の send.status.waiting は行の状態ラベルで使うため残す。

推奨
Q3 · レイアウト

スペーサーとボタン配置は維持

バッジを消した分だけタイトルとボタンの間が広がる。ヘッダーの高さ・余白・ボタンの表示条件（待機 0 件、再試行可能 0 件）は変えない。
